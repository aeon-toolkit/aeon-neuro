Examples
========

The classification notebook generates a complete BrainVision to BIDS to
classification workflow with explicit channel mapping and participant-held-out
evaluation. It uses ordinary aeon classification and CSP+LDA on the same cases.

See the `classification notebook
<https://github.com/aeon-toolkit/aeon-neuro/blob/main/examples/classification.ipynb>`_
for the runnable walkthrough. Installation and command-line execution are
described in `examples/README.md
<https://github.com/aeon-toolkit/aeon-neuro/blob/main/examples/README.md>`_.
